🚀 QUICK START

1. Installation des dépendances:
   $ flutter pub get

2. Lancer l'app:
   $ flutter run -d edge

3. Utiliser dans un écran:
   
   import 'package:provider/provider.dart';
   import 'providers/student_provider.dart';
   
   // Ajouter
   context.read<StudentProvider>().addStudent(
     name: 'Ahmed',
     parentPhone: '123456',
     markazId: 'markaz1'
   );
   
   // Afficher
   Consumer<StudentProvider>(
     builder: (context, provider, _) {
       return ListView(
         children: provider.students.map((s) => 
           ListTile(title: Text(s.name))
         ).toList(),
       );
     },
   )

💡 KEY DECISIONS

1. Provider (not Riverpod) for simplicity
2. ChangeNotifier pattern (easy to learn)
3. In-memory storage (ready for persistence layer)
4. Equatable for model comparison
5. UUID for unique IDs (firebase-ready)
6. Separation of concerns (models, providers, UI)
7. Documentation-first approach
8. Modular file structure
